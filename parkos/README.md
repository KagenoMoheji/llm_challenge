# 駐車予約プラットフォーム
- MaaS用の各種自動車が駐車する場所の確保が難しい．調整も大変．
- 駐車予約プラットフォームに駐車場提供者が登録し，MaaSサービスがその予約可能駐車場所の検索・予約・使用・リリースすることをAPI叩くことサービスとして提供する．
- 個人用地(駐車場・ガソリンスタンド・ビル前空間等)・自治体・ひいては国(道路脇)を相手にビジネス展開．
- API叩くプラットフォームなので，海外て買いも可能．
- 競合は移動販売車系のサイト．
- 追加料金払えば後述の宅配便ロッカー搭載車が止められる場所の優先予約権あるいは独占権の獲得できる、もあると良いかも

# 宅配便ロッカーMaaS
- 運送業者が不足する2024？年の問題の解消案
- 従来の宅配は宅配先への移動が発生する．宅配ボックスも結局移動が発生する．この移動すら自動化させよう．
- 上記の駐車予約プラットフォームをベースとして，MaaS利用者が宅配便ロッカー車に配置してほしいところを探す際に予約プラットフォームに近場の予約個所を検索して仮予約(これの排他制御がむずそうだな…)．MaaS利用者が予約したら予約プラットフォーム当てに確定(30分・1時間単位のどれにするかはMaaSサービス提供側でAPIパラメータで設定しておく．単位によって料金変動)
