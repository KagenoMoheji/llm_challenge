# schecker = SCHEdule cliCKER

開いているWebページ（Claude等）のボタンやHTML要素を選択し、指定した日時に自動でクリックを試行するChrome拡張機能です。

---

## 🌟 主な機能

- **直感的な要素選択 (インスペクター)**:
  - 「要素を選択する」ボタンを押して画面上のボタンをクリックするだけで対象を登録できます。
  - セレクタだけでなくボタンのテキスト（「続ける」「再開」等）やXPathを併用し、SPAでクラス名が変わっても柔軟に再検知します。
- **Claude 回復時刻の自動検出**:
  - Claudeの画面上にある「利用枠はMM月dd日のHH:mmに回復します」などの文言を自動検出して、日時フィールドにワンクリックで反映できます。
- **リトライ付き自動クリック**:
  - 指定日時になったら対象タブでクリックを試行します。
  - 回復直後にボタンがまだ `disabled` だったりレンダリング中だったりする場合に備え、**3秒おきに最大10回自動リトライ**します。
- **子要素クリック試行トグル (新機能)**:
  - 選択した要素が外側のラッパー（div等）で、真のクリック対象（buttonやaタグ等）が子要素にある場合に対応。
  - トグルをONにすると、指定要素だけでなく**内包されている全子要素（buttonやリンク等のインタラクティブ要素を優先）も順次クリックを試行**します。
  - トグルOFF（デフォルト）時は、従来通り選択要素単体のみをクリックします。
- **デスクトップ通知**:
  - 成功・失敗時にChrome通知でお知らせします。
- **テストクリック機能**:
  - スケジュール設定前に「今すぐテストクリック」で動作確認できます。

---

## 🚀 インストール手順（ローカル読み込み）

1. **Google Chrome** を開きます。
2. アドレスバーに `chrome://extensions` と入力してEnterキーを押します。
3. 右上の **「デベロッパー モード」** のトグルスイッチを **オン** にします。
4. 左上に表示される **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
5. 以下のフォルダを選択します：
   ```
   $HOME\.gemini\antigravity\scratch\scheduled-clicker-extension
   ```
6. ツールバーのパズルアイコン（拡張機能）から **「Scheduled Clicker」** をピン留めしておくと便利です。

## 📖 使い方

1. **Claudeのページを開く**:
   - 利用枠制限がかかっているチャット画面を開いた状態にします。
2. **拡張機能のポップアップを開く**:
   - ツールバーのアイコンをクリックします。
3. **対象ボタンを選択**:
   - 「🎯 ページ上で要素を選択する」をクリックします。
   - Claude画面に戻り、マウスを動かすと要素が青くハイライトされます。
   - 「続ける」ボタンをクリックして確定します。（キャンセルは Esc キー）
4. **日時を設定**:
   - もう一度拡張機能アイコンを開きます。
   - 画面内に回復時刻の案内があれば **「💡 検出: ... [適用]」** が表示されるので「適用」を押すか、カレンダー入力欄や `+5分` などのクイックボタンで時刻を指定します。
5. **スケジュール登録**:
   - 「📅 スケジュール登録」をクリックします。
   - これで完了です！PC・Chromeを起動したままにしておけば、指定時刻に自動でタブがフォーカスされクリックが実行されます。
