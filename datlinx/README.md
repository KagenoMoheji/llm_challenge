# datlinx (DATa LIneage lyNX)

`CREATE PROCEDURE` / `CREATE FUNCTION` / `CREATE VIEW` / `CREATE TABLE` のSQLファイルの `FROM/JOIN` および `INSERT INTO` を解析し、依存関係マップ（データリネージ・マインドマップ）の生成・検索を行うツールです。

## Quick try app
https://kagenomoheji.github.io/llm_challenge/datlinx/index.html

## Quick try VSCode extention
Download [the vsix file](https://github.com/KagenoMoheji/llm_challenge/tree/main/datlinx/vscode-ext/dist) and install it in VSCode.
- **エクスプローラー右クリック**: 任意のSQLフォルダを右クリックして「`datlinx: SQLフォルダを解析してマインドマップを開く`」
- **コマンドパレット (`Ctrl+Shift+P`)**:
  - `datlinx: ワークスペースの全SQLを解析して開く`
  - `datlinx: サンプルSQLデータで開く`

## 🌟 主な機能

- **[1] SQLフォルダ・ファイル入力**:
  - `CREATE PROCEDURE` / `CREATE FUNCTION` / `CREATE VIEW` / `CREATE TABLE` のDDLが書かれた `*.sql` ファイル群をまとめたフォルダを一括読み込み（`<input webkitdirectory>`、エクスプローラー右クリック、ドラッグ＆ドロップ対応）。
  - サンプルSQL (13件: テーブル定義やINSERT文を含む) をボタン一つで即座に読み込めるデモ機能内蔵。
- **[2] 依存関係マインドマップ自動描画**:
  - 指定された正規表現パターンに基づき、SQL内の `FROM` / `JOIN` 節から依存元のテーブル名・プロシージャ名・ビュー名を抽出。
  - 左側に「依存元（テーブル等）」、右側に向かって「依存先（ビューやプロシージャ）」を滑らかなベジェ曲線（矢印付き）で結ぶ階層的マインドマップを自動レイアウト。
  - ノード間に十分なマージン（水平・垂直）を取り、重なりのない美しい自動センタリング配置。
  - ノードは自由にドラッグ移動可能（接続線がリアルタイム追従）。
  - マウスホイールでのズーム、ドラッグによるパン移動、全体表示フィットボタンを完備。
- **[3] 検索フォーム（部分一致ハイライト）**:
  - テーブル名・プロシージャ名・ビュー名の一部を入力すると、該当ノードが薄い橙色背景にハイライトされ、キャンバスが該当ノードへスムーズにフォーカス。
- **[4] 依存関係の多方向洗い出し（3色ビジュアル分類）**:
  - マインドマップ上の任意の要素（テーブル/プロシージャ/ビュー）をクリックすると、一目でデータフローの系譜を洗い出せます。
    - **選択要素**: **薄い橙色背景**（オレンジ枠）
    - **依存元（上流の要素・親）**: **薄い緑色背景** ＆ **依存線・矢印が緑色**
    - **依存先（下流の要素・子）**: **薄い赤色背景** ＆ **依存線・矢印が赤色**
    - 関係のない要素は自動でディミング（半透明化）され、対象のデータリネージが鮮明に浮かび上がります。
  - キャンバスやノードのドラッグ操作時にハイライトが外れない安心の操作性。
- **[5] INSERTプロシージャの現在地保持 ＆ 重複TABLE管理**:
  - プロシージャ内の `INSERT INTO <target_table>` を自動抽出し、投入先テーブルをプロシージャ自身の「現在地」として保持。
  - プロシージャノード上に「↳ 投入先: テーブル名」バッジを表示。
  - **右サイドバーの上下分割**:
    - **上段**: 解析済みSQLファイル一覧
    - **下段**: プロシージャの投入先テーブルと `CREATE TABLE` の重複テーブル名一覧
    - 水平スプリッターハンドルで上下の高さを自由にドラッグリサイズ可能。
    - 各セクションはハンバーガーボタンでワンクリック折りたたみ可能。
  - **重複 `CREATE TABLE` の非表示トグルスイッチ**:
    - スイッチをONにすると、重複している `CREATE TABLE` ノードをマインドマップから非表示化。
    - 投入元プロシージャが現在地（実体）となり、投入先テーブルを参照する下流ノード（ビューなど）へ直接接続するすっきりとした直結リネージを表示。
  - **右サイドバー連動の自動拡張**:
    - 右サイドバーを非表示（折りたたみ）にすると、キャンバスの表示領域が画面右端まで100%自動拡張。
