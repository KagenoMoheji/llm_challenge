# datlinx - SQL Lineage Mindmap

**datlinx（DATa LIneage lyNX）** は、`CREATE PROCEDURE` / `CREATE FUNCTION` / `CREATE VIEW` のSQLファイル群から `FROM/JOIN` を解析し、依存関係（データリネージ）をマインドマップ形式で視覚化・検索できるVS Code拡張機能です。

複雑に絡み合うストアドプロシージャ、ビュー、基底テーブルの依存関係を一目で俯瞰でき、影響調査や仕様把握を劇的に効率化します。

---

## 🌟 主な機能

- 🗺️ **自動マインドマップ生成**: SQLフォルダまたはワークスペース全体の `.sql` ファイルを走査し、左側（依存元）から右側（依存先）へ流れる有向グラフを自動配置。
- 🎨 **3色の直感的な依存関係洗い出し**:
  - **選択要素**: **薄い橙色背景**
  - **そこに至るまでの依存元 (上流)**: **薄い緑色背景** ＆ **緑色依存線・矢印**
  - **その後ろの依存先 (下流)**: **薄い赤色背景** ＆ **赤色依存線・矢印**
  - 無関係な要素は自動でディミング（半透明化）され、目的の系譜がくっきり浮き上がります。
- 🔍 **インクリメンタル検索**: 部分一致で目的のテーブル・プロシージャ・ビューを検索し、薄い橙色背景で即座にフォーカス。
- 🔗 **VS Codeエディタとのシームレス連携**: マインドマップ上のノードから直接VS Codeエディタで該当の `.sql` ファイルを横並びで開くことが可能。
- 🖱️ **快適なキャンバス操作**: マウスホイールでのズーム、ドラッグによるパン移動、ノードの自由ドラッグ移動（接続線がリアルタイム追従）。
- 📴 **完全オフライン動作**: 外部CDNやネットワーク不要で、セキュアな隔離環境や社内環境でも軽快に動作。

---

## 🚀 使い方

### 1. フォルダを指定して開く
- エクスプローラーでSQLファイルが入ったフォルダを右クリックし、**「datlinx: SQLフォルダを解析してマインドマップを開く」** を選択します。
- または、コマンドパレット（`Ctrl+Shift+P`）から `datlinx: SQLフォルダを解析してマインドマップを開く` を実行します。

### 2. 現在のワークスペース全体を解析する
- コマンドパレット（`Ctrl+Shift+P`）から **`datlinx: ワークスペースの全SQLを解析して開く`** を実行します。

### 3. サンプルデータで試す
- コマンドパレットから **`datlinx: サンプルSQLデータで開く`** を実行すると、内蔵された10個のサンプルSQLによるマインドマップが即座に立ち上がります。

---

## 🎮 マインドマップの操作方法

- **依存関係の洗い出し**: 任意のノードをクリックすると、上流（緑）と下流（赤）がハイライトされます。キャンバスの背景をクリックすると選択解除されます。
- **検索**: 上部検索バーに名前を入力すると、該当ノードが橙色でハイライトされ、画面中央にフォーカスされます。
- **ファイルを開く**: ノード右下の `📄` アイコンをクリックすると、VS Codeエディタで該当のSQLファイルが開きます。
- **キャンバス移動**: 背景をドラッグするとパン移動、マウスホイールでズームイン/ズームアウトできます。
- **全体表示**: 画面右下の `⛶` ボタンで全体が画面に収まるよう自動調整されます。
